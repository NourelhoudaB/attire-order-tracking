# Ressources

Les polices Barlow et Barlow Condensed sont distribuées par Fontsource sous SIL Open Font License. Le logo TENUE PRO provient de la pièce jointe du client ; aucun logo alternatif n’a été généré.

La liste de mots de passe interdits reprend les 1 000 premières lignes du fichier public [SecLists · 10k-most-common](https://github.com/danielmiessler/SecLists/blob/master/Passwords/Common-Credentials/10k-most-common.txt). SecLists est distribué sous licence MIT. Cette liste est une ressource de validation générique ; elle ne contient aucune information de connexion fournie par le client.

Les bibliothèques et leurs versions sont inventoriées dans package.json et package-lock.json. Les composants applicatifs reposent sur des bibliothèques open source ; l’hébergement, la base, le stockage d’archives et le service Identity utilisent les primitives Netlify de cette cible de déploiement.
